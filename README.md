# AI Models Tier List

Безкоштовний сайт для тір-листа AI-моделей: S–D, 57 брендів з логотипами, перетягування карток і посилання «Share Ranking».

Сайт складається з одного файлу `index.html`. Він не потребує сервера, бази даних, ключів API чи реєстрації відвідувачів.

---

## Як опублікувати безкоштовно на GitHub Pages

Банківська картка не потрібна.

1. Зайди на **https://github.com/signup** і створи безкоштовний акаунт: email, пароль, ім'я користувача. Ім'я стане частиною адреси сайту.
2. Підтверди email: GitHub надішле лист з кодом.
3. Справа вгорі натисни **+** → **New repository**.
4. У полі **Repository name** напиши `ai-tier-list`.
5. Вибери **Public**. Безкоштовні сайти на GitHub Pages працюють лише з публічними репозиторіями.
6. Натисни **Create repository**.
7. На новій сторінці натисни посилання **uploading an existing file**.
8. Перетягни у вікно браузера файли **`index.html`**, **`README.md`** і **`.nojekyll`** з папки сайту.
   - Якщо `.nojekyll` не видно (Windows ховає файли з крапкою), це не страшно: сайт працює і без нього.
9. Внизу натисни зелену кнопку **Commit changes**.
10. Відкрий вкладку **Settings** репозиторію, зліва вибери **Pages**.
11. У блоці **Build and deployment**:
    - **Source**: `Deploy from a branch`;
    - **Branch**: `main`, папка `/ (root)`;
    - натисни **Save**.
12. Зачекай 1–3 хвилини й онови сторінку **Settings → Pages**. Угорі з'явиться адреса на кшталт:
    `https://ТВОЄ-ІМʼЯ.github.io/ai-tier-list/`
13. Відкрий цю адресу. Це твій сайт, і його бачить будь-хто без акаунта.

### Як оновити сайт пізніше

1. Відкрий репозиторій → натисни на файл `index.html`.
2. Натисни значок олівця, щоб редагувати, або **Add file → Upload files**, щоб завантажити нову версію з тією самою назвою.
3. Натисни **Commit changes**. Через 1–3 хвилини сайт оновиться.

## Як працюють посилання «Share Ranking»

- Увесь тір-лист (назва, опис, назви тірів, кольори, порядок карток) стискається й записується прямо в посилання, після знака `#`.
- Частина після `#` **не надсилається на сервер**, вона лишається в браузері. Тому нічого не зберігається «в хмарі»: **посилання і є збереженням**.
- Людина, яка відкриває посилання, бачить твій тір-лист у режимі перегляду. Кнопка **Copy & Edit** створює її власну копію, яку можна редагувати.
- Якщо після поширення ти щось змінив, потрібне нове посилання.

## Де зберігаються «My rankings»

- Твої тір-листи зберігаються в `localStorage`, тобто тільки в цьому браузері на цьому пристрої.
- Якщо очистити дані браузера або відкрити сайт на іншому пристрої, їх там не буде. Щоб перенести тір-лист, використай **Share Ranking** або **Export JSON** / **Import JSON**.

## Голосування

- **Live Voting Poll** і **Community Rank** у безкоштовній версії працюють у **локальному режимі**: голоси зберігаються тільки у твоєму браузері. Справжнє спільне голосування потребує сервера, і це план на наступний етап.

## Технічні деталі (для розробника)

- Один статичний файл `index.html`: HTML, CSS і чистий JavaScript, без збірки й залежностей.
- Логотипи: [LobeHub Icons](https://github.com/lobehub/lobe-icons) (ліцензія MIT), вбудовані в файл як SVG. Для брендів без логотипа використовується значок з ініціалами.
- Формат посилання: `#r=<base64url(deflate-raw(JSON))>`, запасний варіант `#j=<base64url(JSON)>`. Максимум 12 000 символів, усі дані перевіряються при відкритті.
- Збереження: `localStorage` під ключем `ai-tier-store-v2`. Старий ключ `ai-tier-list-v1` переноситься автоматично.
- `.nojekyll` вимикає обробку Jekyll на GitHub Pages.
- Альтернатива: Cloudflare Pages → **Create → Pages → Upload assets**, перетягнути папку. Теж безкоштовно, але потрібен акаунт Cloudflare.
